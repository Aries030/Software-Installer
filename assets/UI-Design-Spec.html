Software Installer — UI 设计规范

v2.0 · 现代化暗色主题 · 三栏 + 命令栏布局 · 面向 IT 运维批量部署场景

1. 设计理念

1

三栏 + 命令栏布局

左侧统计/类型筛选,中间安装包列表,右侧详情面板,顶部统一命令栏。信息分区清晰,减少认知成本。

2

卡片式列表项

每个安装包是一张信息卡片,集成勾选框 + 类型徽标 + 文件名 + 大小 + 状态,一眼获取全部信息。

3

渐进式披露

默认简洁,选中后才展开参数编辑和命令预览。避免信息过载。

4

状态全可见

扫描、选择、安装每个阶段都有明确视觉反馈。进度条 + 日志 + Toast 三层反馈体系。

5

键盘友好

IT 运维场景,全键盘操作可达。双击选择、空格切换、Enter 安装、Esc 取消。

3.1 左栏 — 统计与类型筛选

固定宽度 140px,包含:

  • 统计卡片: 总数(大号蓝色数字) + 已选/已装(并排小卡片)
  • 类型筛选: 按扩展名分组,点击可筛选,带计数

3.2 中栏 — 安装包列表

卡片式列表,每张卡片高度 56px,包含:

  • 勾选框(16×16,圆角 4px)
  • 类型徽标(36×22,圆角 5px,按类型配色)
  • 文件名(12px / 500,超长省略)
  • 子标题:分类 · 大小(10px,灰色)
  • 状态标签(右侧):未选择 / 已选择 / 安装中 / 已完成 / 失败

3.3 右栏 — 详情面板

固定宽度 200px,选中卡片后显示:

  • 文件名(13px / 500)
  • 完整路径(10px Consolas,灰色)
  • 安装参数输入框(可编辑,留空用默认)
  • 命令预览(只读,等宽字体)

6. 实现建议

6.1 技术栈

组件技术说明
GUI 框架customtkinter 5.2+暗色主题原生支持,圆角扁平控件
图标Pillow + CTkImageLOGO 通过 CTkImage 加载,支持 HighDPI
打包PyInstaller --onefile单文件 exe,内嵌全部资源
字体Segoe UI / ConsolasWindows 原生字体,无需打包

6.2 customtkinter 实现要点

  • 三栏布局: 用 grid + columnconfigure(weight=1) 实现弹性中栏
  • 卡片列表: CTkScrollableFrame 内放自定义 CTkFrame 行
  • 类型徽标: CTkLabel + fg_color + corner_radius=5
  • 进度条: CTkProgressBar + progress_color 按状态切换
  • Toast: place() 定位 + after() 自动销毁
  • LOGO: CTkImage(不要用 PIL.ImageTk.PhotoImage,会有 HighDPI 警告)

6.3 性能注意

  • 列表超过 100 项时,考虑虚拟滚动或分页(当前场景一般不超过 50 项,无需优化)
  • 安装过程在子线程执行,通过 queue.Queue + after() 回传 UI 更新
  • 扫描目录用 os.walk + 忽略列表,避免扫描 venv / node_modules 等
